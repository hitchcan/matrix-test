## 启动

需要 Windows、Node.js 24 或以上及 Google Chrome。Playwright 依赖已安装，新电脑先执行 `npm ci`。

```powershell
cd 'E:\矩阵调研2\matrix-studio'
npm start
```

打开 http://127.0.0.1:4318 。停止时在终端按 Ctrl+C。端口占用时：

```powershell
$env:PORT = '4319'
npm start
```

或运行 `启动展示.cmd`。界面、数据库、素材全在本机，不发布到云端。

## 演示操作

1. 内容工作室选择“长文章”，填写标题、正文；视频类型需要上传一份视频文件。
2. 保留知乎、B站两个演示账号，可单独调整各平台文案。
3. 点击“校验内容”，再点击“创建分发任务”。
4. 在任务列表打开“查看 / 处理”，核对账号、文案、素材，再继续演示。
5. 正常流程生成 `DEMO-` 前缀的模拟回执，没有真实作品链接。
6. 可在内容页选择“会话失效”或“提交结果不明”场景，演示人工接管。

同一分发意图重复点击不会创建重复任务；修改内容或目标账号后会形成新的分发意图。提交中的任务重启后进入待确认，不自动重发。页面未保存的编辑在刷新浏览器后丢失，请使用“保存草稿”；已保存草稿、素材和任务支持重启恢复。

## 账号授权与真实发布

在账号管理添加账号，点击“登录 / 打开后台”，在工具创建的独立 Chrome 窗口自行扫码。工具自动读取本人资料区的平台ID，或监听页面自己请求的同源当前用户响应；没有可靠身份时保持等待，不把昵称或Cookie存在当作已登录。抖音可选择视频，小红书可选择视频/图片笔记。任务开始时和提交前检查身份，并按账号隔离持久环境与加密补存会话Cookie。

## 小红书发布

选择“视频”时仅选择一个视频；选择“图片笔记”时上传一张或多张图片，上传次序随素材选择次序保留，不混入视频。长文章类型不会自动转换为小红书笔记。可以填写小红书专属标题和正文，选择发布方式、静默开关和AI声明，再创建任务。

执行器打开官方创作后台，切换“上传视频 / 上传图文”，上传素材，等待编辑区域出现，填写内容；最终提交前核对身份、文本和作品声明。点击后仅凭本次成功提示确认“已提交”，没有真实稿件ID/作品链接时不编造。平台验证、字段变化、封面或必填项不完整时可从任务打开可见窗口处理。小红书的高级封面、标签、定位等控件未自动适配。

无法确认登录账号时会暂停发布，不会通过放行未知身份掩盖问题。已识别的真实账号任务会上传素材到官方后台、尝试填写标题正文，并等待人工检查。演示账号任务仍仅模拟。身份读取和发布页面规则仍需真实账号联调，匹配失败时会暂停。

## 文章排版

切换到“长文章”后，可编辑标题级别、加粗、斜体、下划线、列表、对齐、字体字号、颜色、链接、图片及表格；知乎和 B站版本可分别编辑。可以从 Word 复制粘贴，或点击“导入 Word”选择 `.docx`（20MB以内，不支持旧 `.doc`）。图片可插入本机文件；网页远程图片链接不自动抓取。

草稿同时保存正文文本和经过过滤的 HTML，重新打开、预览及任务快照保留格式。发布准备使用 HTML 粘贴到平台富文本区域，发现基础格式丢失时暂停。Word 页眉页脚、分页、浮动对象及所有打印版式不属于本版兼容范围；目标平台可能限制字体、颜色、表格或图片。富文本粘贴会使用本机剪贴板，可能替换原剪贴板内容。

发布规则在 `config/adapters.json`，身份规则在 `config/identity-selectors.json`。默认提供知乎视频/文章、B站视频/专栏的待验证初始定位。最终提交按钮和成功标志默认未配置，核验页面后补齐才可执行最终点击。封面、分区和声明需要在官方页面手工核对。不要在聊天或普通配置中提交 Cookie、密码或 token。

## 数据与限制

- SQLite：`.data/studio.sqlite`；素材：`.data/assets/`。目录已加入 `.gitignore`。程序暂不提供素材清理、账号删除与数据库迁移管理。
- 本地 HTTP 服务只监听 `127.0.0.1`；写接口使用会话令牌，并拒绝跨源请求。
- 单文件512MB是本展示版限制，不是任何平台限制；仅校验基础内容与 MIME 声明，未实现编码、真实格式、视频时长、比例、封面、分区、版权声明及平台规则校验。真实发布前必须补齐。
- 上传图片 / 视频会复制到本地目录；仅保存文件名不算上传完成。暂不支持视频断点上传、媒体转码或多段视频。
- 素材预览不保证所有编码可播放。服务端仅内联显示常见位图和视频类型，其他格式不作为可执行网页渲染。
- 无定时发布、云端执行、评论私信、统计与团队权限。数据库未加密、不存 Cookie 明文；Chrome Profile 含敏感站点存储，额外会话 Cookie 使用 Windows 用户级 DPAPI 加密。不要分享 `.data/`。

## 素材库管理

- 在「素材库」选择上传归档日期，点击「添加素材」批量上传图片或视频；每个文件上限 512 MB。内容工作室上传的素材默认归档到当天。
- 素材按归档日期分组，可按名称搜索、按具体日期与图片/视频类型组合筛选，并切换日期先后顺序。内容工作室的素材选择窗口也按日期分组。
- 点击素材「编辑」可修改名称和归档日期，文件扩展名须保留；上传时间保持原始记录。
- 点击「删除」并确认后，永久删除本地素材和对应的浏览器上传缓存。正在编辑但未保存的内容会同步移除该素材选择、封面或内嵌图片。
- 为避免草稿缺图或任务失败，已保存草稿（包括平台专属正文、封面）或未结束任务引用的素材禁止删除。先编辑并保存草稿以解除引用，或结束相关任务，再返回删除。
- 归档日期采用香港时区（UTC+8）的日历日期，与上传时间分别保存。升级后旧素材自动按原上传时间补齐日期，原文件与草稿不变。

素材接口沿用本地会话令牌校验：`POST /api/assets` 可通过 `X-Archive-Date: YYYY-MM-DD` 指定归档日期；`POST /api/assets/:id` 接收 `{name, archiveDate}` 更新信息；`DELETE /api/assets/:id` 删除无引用素材。日期信息保存在独立的 `asset_dates` 表中，兼容原 `assets` 表结构。

## 账号管理与平台选择

账号管理提供「全部平台 / 抖音 / 哔哩哔哩 / 知乎 / 小红书」筛选及账号数量。选择某个平台后，新增账号表单会切换到该平台；账号状态自动更新时保留当前筛选和未提交的账号备注。

每张账号卡片（含演示账号）都可点击「删除账号」，确认后关闭对应浏览器、清理该账号专属的本机登录目录，并删除工作台中的账号记录。这不会注销平台账号；重新添加需再次登录。原「停用连接」仍只关闭连接，保留本机登录环境。

有排队、失败待处理、等待人工、验证中或结果未知等未结束任务的账号不可删除。请先取消尚未提交的任务，或核对提交结果并关闭任务。已结束任务保留原账号名称、内容快照和回执供查看；账号删除后不能从历史任务重新打开该账号浏览器。账号全部删除后，重启不会重新生成演示账号。

内容工作室的「发布账号平台」下拉框支持分平台选择账号，切换平台保留已有选择，允许一次选择多个平台的账号。内容类型不受平台支持时仍禁用相应账号。

删除接口：`DELETE /api/accounts/:id`，须提供有效的 `X-Studio-Token`。有未结束任务时返回 409，账号已删除或不存在时返回 404。

## 添加账号与服务更新

在账号管理点击「添加账号」后，工作台会先保存待登录记录，再自动打开所选平台后台。请在平台页面扫码，识别到真实身份后才显示「已登录，可发布」。若后台未能打开，记录会保留，可点击「登录 / 打开后台」重试。未登录、未扫码的账号也可以删除。

工作台会检查后台是否支持账号删除。页面已更新而后台服务仍是旧进程时，显示重启提示并暂时禁用删除按钮，避免将接口缺失误认为账号不存在。手动启动的服务需在原窗口停止后重新运行「启动展示.cmd」；仅刷新页面不会替换运行中的后台代码。
