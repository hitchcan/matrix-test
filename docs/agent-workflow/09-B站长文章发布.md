# B站长文章发布

2026-11-12。新增 bilibili-article 发布通道，使用当前官方新版专栏编辑器：https://member.bilibili.com/york/read-editor 。旧配置中的 /platform/upload/text/edit 已替换。依据官方公开编辑器和其公开静态资源确认标题、正文、发布设置、AI 声明、最终按钮及成功提示结构；未使用用户 Cookie 请求私有投稿 API。

## 使用

重启服务并刷新页面后，在任务中选择 B站账号的“长文章”，或在内容工作室选择长文章并勾选 B站账号。账号需保持登录且拥有平台要求的投稿权限。

支持标题、富文本正文及正文内本地图片。图片复用原生剪贴板文件上传，按原文位置逐张插入，等待 B站图片域名的图片加载成功。任务生成稿件会保留 AI 辅助创作声明；提交前必须读回与任务相同的声明状态。不会自动把 AI 声明替换成原创声明，不修改平台原创声明选项。

默认可使用平台的自动文字封面。自定义封面可在官方原页人工设置；工具会检查已开启的自定义封面是否完成加载，未完成时不发布。目前未自动上传或裁剪长文章自定义封面。平台定时发布如已开启，工具暂停供用户核对，不自行改写时间；周期任务可继续使用工作台调度。

## 核验与限制

- 按真实编辑器的 maxlength 检查标题，不静默截断模型稿件。
- 对正文文字、样式和图片复核；排除 B站明确标记为空的图片注释占位提示，真实图片注释仍属于校验内容。
- 图片加载失败、仅有本地 blob/data 地址或上传遮罩未消失时阻断。支持与原图片工具相同的 PNG/JPEG/GIF/WebP 输入和单张像素限制；原生上传会转换为 PNG，动图不保证保留动画。
- 最终按钮仅定位新版固定底栏内唯一“发布”，不把“发布设置”或“保存为草稿”当成提交。
- 点击前仍检查账号、文案、声明及持久提交门禁，失败或超时不自动重复点击。
- 成功只接受专栏编辑器的“你的专栏已提交成功”提示。该提示代表平台接收，不能证明审核通过或公开可见；页面没有作品 ID 时不编造编号或作品链接。
- 创作中心查稿仍须独立配置 B站 verifier 规则。作品链接识别已扩展至新版 opus 与旧版 cv 链接，保留视频 BV 标识兼容。
