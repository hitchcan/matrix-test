# 定时任务与素材发布

2026-11-12。此文补充 06，新增需求以本次用户指令为准，01–03 中旧称及早期方案保留作背景。

## 新建任务

内容方式有三种：

- **AI 生成**：沿用现有流程。agent 根据事实与授权素材生成文章、图文或视频场景；视频仍交给配置的视频模型服务生成。
- **手选素材直接发布**：选定素材，填写发布标题及“事实与参考资料”中的正文/配文，不调用生成 LLM，也不调用视频生成服务。配文为空时使用标题，不会自动公开素材用户备注。文章和图片笔记使用所选图片；视频每个账号每期使用一份视频，多份视频按该账号的使用记录轮换，未使用的优先。同一个任务可包含图片、视频及对应目标，执行时按目标形态过滤。
- **agent 从日期区间选材发布**：设置归档开始及结束日期（包含首尾日期），填写主题与选材要求。每次创建运行时重新读取区间内的素材和用户备注，所以保存任务后新上传、且归档日期在区间内的素材也可成为下一次候选。agent 选择原素材并生成标题、配文；视频每期只选一份原视频，直接上传该文件，不生成新成片。下方素材卡片的手工勾选不限制区间范围。

区间选材先按目标形态过滤：视频目标只看到视频，文章与图文目标只看到图片。模型返回区间外、错误类型或多个视频 ID 都会阻断，不会扩大授权范围补选。每次运行全区间最多100份素材，超过上限时该次运行显示阻断原因；可缩小范围后创建新运行。读取图片与视频画面的方式仍最多8份、每份150MB；可选择名称与备注模式使用更大的候选范围。

当前三种方式都可以采用原有人工发布或自动发布方式；自动发布继续经过身份、内容、声明和持久提交门禁。AI 生成或 agent 生成配文会使用 AI 辅助创作声明；手选直接发布不声明本次使用了生成模型。原素材如存在其他平台需要人工填写的属性，仍按原发布适配器规则处理。

## 用户备注

素材库上传区域可填写本批素材备注，批量文件会使用同一备注。也可点击素材的“编辑”分别修改名称、归档日期和用户备注，每份最多2000字。素材卡片显示备注，素材库及任务素材搜索支持名称和备注。

备注适合描述画面内容、主题、适合的账号和使用要求。任务内原有“素材描述”仍是该任务的补充要求；agent 收到素材库备注与任务补充。备注、OCR、图片及视频内容均作为参考数据，不能改变发布权限和系统约束。

运行保存候选素材名称、类型及备注快照。之后修改备注不会改变已创建运行的选材上下文；下一次运行使用更新后的备注。素材冷却按账号生效。直接发布的视频采用先未使用、后最久未使用的顺序；不限制冷却时，队列用完后会继续轮换。需要避免近期重复时请选择冷却时间。

## 定时选择

所有新任务固定使用北京时间 `Asia/Shanghai`（UTC+8），无需填写或选择时区。日期采用日期选择器，小时、分钟采用下拉选择。

支持：

- 仅手动运行。
- 指定日期时间，单次发布。
- 按固定分钟、小时或天数间隔运行。
- 每天设置一个或多个发布时段。
- 每周选择星期及一个或多个时段。
- 每月选择日期及一个或多个时段。该月不存在的日期跳过，例如每月31日不在2月执行。

最多24个每日时段，重复时段去重。开始日期和时间是执行下界；结束日期和时间可选，是执行上界。选择提前生成后，会提前准备成品，在发布时间到达后才创建分发任务。多个目标由现有 worker 依序处理，平台页面操作、验证及审核可能延后实际上线。

错过周期可选只执行最近一期，或迟到超过一分钟就跳过；不会为离线期间每一期集中补发。生成未完成时已经进入下一期，旧期会阻断。任务、下一执行时间及生成成品均持久保存，重启后继续处理。服务需保持运行，应用关闭期间不能准点执行。

例如：每周一、三、五09:30和18:00发布，选择“每周”，勾选对应星期，添加两个时段，选择提前5分钟。若原视频有多份，搭配“手选素材直接发布”即可按这个频率逐份轮换；若希望 agent 按主题和备注选视频，选择日期区间选材方式。

## 接口兼容

原任务 HTTP 路径与 agent 工具不变。TaskSpec 新增：

```json
{
  "taskMode": "select",
  "assetRange": {"from": "2026-11-01", "to": "2026-11-30"},
  "schedule": {
    "kind": "weekly",
    "timezone": "Asia/Shanghai",
    "startAt": "2026-12-01T00:00:00+08:00",
    "endAt": null,
    "times": ["09:30", "18:00"],
    "weekdays": [1, 3, 5],
    "prepareLeadSeconds": 300,
    "latePolicy": "latest"
  }
}
```

`taskMode` 可选 generate/direct/select，旧模板缺省 generate。`schedule.kind` 可选 manual/once/interval/daily/weekly/monthly；interval 使用 `intervalSeconds`，monthly 使用 `monthDays`（1–31），weekly 使用 `weekdays`（0为周日）。旧的 startAt + intervalSeconds 接口继续兼容，不改变既有运行与提交账本。

`POST /api/assets/{id}` 新增 `note`，不传时保留原备注。上传时填写的备注在文件成功保存后通过同一素材编辑接口保存，避免长中文备注超过 HTTP 请求头长度限制。`GET /api/state` 和 agent 的 context 返回素材 note 和 archiveDate。本机 SQLite 新增幂等创建的 asset_notes 表，保留原 assets 表结构，历史素材默认空备注；删除素材时同步删除备注。
