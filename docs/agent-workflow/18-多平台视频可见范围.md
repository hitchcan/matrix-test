# B站与快手视频可见范围

2026-11-17。原先仅抖音支持指定视频可见范围，本轮新增 B站视频和快手视频。视频号现有保存页没有可见范围设置，待补充截图核实，不将后台默认设置视为“仅自己可见”。

内容工作室的发布选项、任务模板的生成与发布区，各有独立的 B站/快手视频可见范围：沿用平台当前设置、公开、仅自己可见。仅作用于对应平台的视频。旧任务和未指定选项不改变权限。

设置保存在 publication.videoVisibility（按 bilibili/kuaishou 分别指定 public/private），任务模板中的 videoVisibility 经运行及目标快照进入分发稿件。前端仅提供有实际页面依据的两个平台，后端拒绝未知平台及其他选项。

B站根据用户截图及保存 HTML 定位 .vu-only-self。隐藏时先展开唯一的“更多设置”，只读 .check-radio-v2-box-checked 对应选项，不操作“在个人空间-投稿中隐藏”等相邻开关。

快手按“查看权限”行限定单选范围，读实时 checked 属性，不用保存 HTML 的 checked 属性推断当前值，不误选“好友可见”。

准备阶段选择并读回指定值；最终提交前只核对，不擅自纠正人工修改的值。若控件缺失、歧义、未生效或已改变，阻断最终门禁。成功回执附带 visibility 核对结果。

测试使用脱敏保存 DOM 和受控浏览器，包括 B站折叠展开、两平台公开/私密切换、未指定不操作及最终门禁阻断。未执行真实投稿，未重启后台。

视频号需要补充视频上传后的设置区截图，尤其是“谁可以看/可见范围”入口及展开后的选项。若网页没有此设置，需明确区分手机端功能与网页能力，不能以草稿或仅主页隐藏代替私密发表。

本轮静态检查通过，全项目回归 265/265 通过。

## 2026-11-17 视频号“仅自己可见”映射

按用户明确要求，视频号可见范围也使用“沿用平台当前设置 / 公开 / 仅自己可见”这组发布选项，不增加单独的草稿选项。“仅自己可见”在执行时映射为官方“保存草稿”；未指定或选择公开仍使用原发表流程。

该选择进入模板、运行和分发快照。保存草稿同样经过账号、文案、视频标注及持久提交门禁，最终仅定位名称精确为“保存草稿”的按钮。按钮缺失或禁用时暂停，不回退到发表。只有本次草稿保存成功提示才记录 action=draft_saved，发表成功提示不能冒充草稿保存成功。

草稿动作保留一次提交名额和原任务账本，但不安排发表核对或自动重发；已有动作的草稿任务拒绝恢复为发表核对/重试。如无明确回执，人工核对草稿箱。工作台显示“草稿已保存”，执行日志和回执明确未发表。内部任务完成状态复用 submitted，不将其显示为平台公开发布成功。

截图确认“保存草稿”按钮；成功提示的实际措辞及草稿箱条目仍需真实账号联调。本轮未真实保存或发表、未重启后台。
