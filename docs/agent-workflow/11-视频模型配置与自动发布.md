# 视频模型配置与自动发布

2026-11-12。本轮完成用户在任务中选择视频模型、调用 API 生成视频并继续发布的配置与执行链路。保留从素材库直接上传原视频，以及 agent 按日期区间选原视频的功能。

## 使用方法

1. 在“任务 → 模型配置”保存可用的 agent 文本模型。agent 负责标题、配文、镜头计划及完整视频提示词，视频服务负责生成成片。
2. 在独立的“视频模型配置”中选择“阿里云百炼 · 万相3.0”，填写所属地域、业务空间 Workspace ID，点击“填写万相接口地址”；也可以粘贴控制台提供的完整生成接口。
3. 填写视频模型名称（默认 wan3.0-video）、对应地域的 API Key，选择时长、分辨率、是否生成声音和每次运行的生成次数限制，保存配置。可选费用估算和上限可同时留空，此时以次数限制执行，实际收费以供应商为准。
4. “保存并检查配置”只做本地检查，不发送生成请求，不代表密钥权限或成片质量已经验证。
5. 新建任务选择“AI 生成”，填写主题、事实、账号定位，选择目标账号的“AI 视频”，在“生成与发布”选择视频模型、横竖比例和定时。要全自动提交请选择“自动发布”；选择“发布前人工处理”时仍会在最终提交前等待用户。
6. 保存并立即运行，或等待定时触发。运行详情可以查看视频模型任务状态、原始任务 ID、视频提示词和生成视频预览。视频和封面自动保存到素材库。

现有视频无需调用生成模型：选择“手选素材直接发布”，勾选视频并设置标题和配文；或者选择“agent 从日期区间选材发布”，让 agent 依据素材备注挑选原视频并编写配文。

## 模型切换

视频配置与文本模型配置互相独立。可保存多份视频配置，设定默认值，并让各个任务选择不同配置。任务选择“使用默认”时，会在创建新运行时确定配置 ID；之后切换默认不会改变该运行。

当前支持两类协议：

- 万相原生异步协议：可配置模型名称、完整地域接口、时长、分辨率、声音开关和密钥。
- JSON 异步网关：用于后续接入不同供应商。将其原生协议适配到下面统一的创建/查询/下载合同；仅修改地址不会自动兼容任意厂商的请求字段。

万相接入按[阿里云官方 API 参考](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)核对：创建接口使用 Workspace 与地域域名、Bearer 鉴权及 X-DashScope-Async: enable；提交 prompt 和视频参数，保存返回的 task_id，再查询同一空间的 tasks 接口，成功后下载 video_url。官方支持的地域、模型权限与密钥需要一致，本实现提供2–30秒和480P/720P/1080P选项。

本轮使用文生视频，不会把素材库的原图片、视频直接上传至万相作为首帧或参考媒体。素材可以用于 agent 理解和编写提示词。万相参考生视频等其他模式不在本轮接入范围。

## 执行与恢复

创建远程视频请求前，事务保存一次生成名额；已发出但响应不明的请求不会自动重建。每个目标只创建一段完整视频，不对每个镜头分别调用视频服务。费用估算为空时只记录次数，不虚构实际金额。

远程 ID 和原视频配置 ID 持久保存，重启后继续查询原任务。临时网络或查询限流失败会在原任务上有限等待重试；持续失败会阻断，可修复后恢复同一目标。凭证错误也会阻断，不将供应商原始报错正文写入运行详情。

切换默认配置或为新任务选择另一配置不影响已在生成的视频。若直接编辑旧配置的接口、模型或视频参数，旧远程任务会因签名变化暂停；恢复原参数后可恢复同一目标。仅更新同一接口的密钥不改变签名。旧环境变量视频任务继续使用环境配置，不会被新默认配置接管。

下载先校验结果主机，不向下载地址携带视频 API Key，并限制文件大小。成片经本地浏览器解码，提取封面、时长与尺寸后归档。之后仍通过原有分发、身份核对、AI 声明和提交门禁。停止运行会阻止迟到结果继续分发；已提交到供应商的生成请求不会因此自动取消，也不能保证供应商不计费。

## JSON 网关合同

将 endpoint 设置为创建接口，例如 https://gateway.example/video/jobs。

创建：POST endpoint，携带配置的 Bearer 密钥，提交：

```json
{
  "model": "future-video-model",
  "request_id": "稳定的本地目标ID",
  "prompt": "agent编写的完整视频提示词",
  "aspect_ratio": "9:16",
  "duration": 5,
  "resolution": "720P",
  "audio": true
}
```

返回 `{"id":"remote-id"}`。网关可用 request_id 实现自己的幂等防重，本地即使网关没有幂等能力也不会自动重发结果不明的创建请求。

查询：GET endpoint/{编码后的remote-id}，仍携带 API Key。返回 `{"status":"running"}`、`{"status":"failed"}` 或 `{"status":"succeeded","video_url":"https://result.example/output.mp4"}`。

结果视频需为本地浏览器可解码的 MP4。下载主机默认为配置接口的主机；若使用独立结果域名，填入“允许下载的额外域名”。万相官方结果域名已内置。重定向不自动跟随，下载不携带接口密钥。

## 数据与接口

- GET/POST /api/video-settings：读取脱敏配置或保存配置。保存支持 id/create/activate/name/provider/endpoint/model/key/clearKey/duration/resolution/audio/downloadHosts/callMicros/maxMicros/maxGenerations。
- POST /api/video-settings/select：传 id 设置默认配置。
- POST /api/video-settings/check：传 id 执行本地参数检查，不发出模型请求。
- TaskSpec 新增 videoModelId；agent 的 save_template 工具使用同一字段，context 返回脱敏 videoProfiles。
- studio.sqlite 新增 video_profiles、video_settings；视频任务迁移16新增 profile_id、poll_failures。历史远程 ID、预算与状态保留。

凭证仅存本机，HTTP 状态、agent context、运行快照及成品不返回密钥。切换供应商或生成接口时不会沿用旧接口密钥。环境变量 MATRIX_VIDEO_* 接入继续兼容；旧环境变量方式仍沿用原有费用配置约束。

## 2026-11-16：新增 Token Plan 供应商协议

Token Plan（含个人版 Lite）与按量付费的万相共用 DashScope 异步视频协议，但域名、套餐密钥和参数范围不同，此前只能用业务空间地址接入。现新增独立的 `tokenplan` 供应商协议，与既有 `wan3`、`json` 并列：

| 项 | 万相（wan3） | Token Plan（tokenplan） |
| --- | --- | --- |
| 生成地址 | `https://<WorkspaceId>.<地域>.maas.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis` | `https://token-plan.<地域>.maas.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis` |
| 查询地址 | 同域 `/api/v1/tasks/{task_id}` | 同域 `/api/v1/tasks/{task_id}` |
| 密钥 | 业务空间的通用密钥，前缀 `sk-` | 套餐专属密钥，前缀 `sk-sp-`；在「我的订阅」页获取，只完整显示一次 |
| 时长 | 2–30 秒 | 3–15 秒 |
| 声音开关 | 提交 `parameters.audio` | 按官方参数表不提交声音开关 |
| 结果下载 | `dashscope-result-*.oss-*.aliyuncs.com`、`dashscope-*.oss-accelerate.aliyuncs.com` | 额外允许阿里云 OSS 存储域名（`*.oss-*.aliyuncs.com`、`*.oss-accelerate.aliyuncs.com`），仍不携带密钥、不跟随重定向 |

工作台行为：供应商选择“阿里云百炼 · Token Plan”后，地域可选择北京或新加坡等 Token Plan 地域，Workspace 输入框固定为 `token-plan` 且只读，辅助按钮直接生成套餐地址；模型下拉补充 `happyhorse-1.1-t2v`、`happyhorse-1.1-i2v`、`happyhorse-1.1-r2v`、`wan3.0-video`；时长选择随供应商切换为 3–15 或 2–30；声音勾选在 Token Plan 下隐藏。保存时仍执行本地校验，不发请求。

同一把套餐密钥可调用该套餐白名单内的全部视频模型：在“视频模型名称”里换成目标模型即可，不需要再申请第二把密钥。若需要让不同任务长期使用不同模型，建议分别为每个模型保存一份视频配置并共用同一密钥——直接编辑旧配置的模型名会改变配置签名，已在生成中的旧远程任务会暂停（可用「恢复这个目标」在原配置下继续查询）。

受控测试新增两项：协议层覆盖提交体（`model`/`input.prompt`/`resolution,ratio,duration`）、`X-DashScope-Async` 与 Bearer 头、任务查询路径映射、OSS 结果下载与越权域名拒绝、域名与时长边界；配置层覆盖 Token Plan 保存、密钥不回显、缺密钥时 `configured=false` 以及 16 秒被拒绝。视频相关 7 项非浏览器测试全部通过；涉及 Chromium 的界面测试需在本机运行 `npm test`。

## 2026-11-18：业务空间可用的视频模型范围

问：在「视频模型配置」里选业务空间（万相3.0）时，模型下拉为什么只有 `wan3.0-video` 和 `wan3.0-video-prime`？

答：那个下拉**只是常用预设**，模型名称本身是自由输入框，业务空间已开通的其他文生视频模型可以直接填模型 ID。预设偏窄是因为此前只在 `wan3.0` 系列上验证过。

本次调整：

- 万相预设扩展为 `wan3.0-video`、`wan3.0-video-prime`、`wan2.6-t2v`、`wan2.5-t2v-preview`；界面提示改为「列表仅为常用预设；业务空间已开通的文生视频模型可直接填模型 ID」。
- 只列文生视频（t2v）模型。`wan2.6-i2v`、`wan2.5-i2v-preview` 等图生视频模型需要首帧图片，本工具当前只做文生视频，不提供入口。
- 按模型限制提示词长度：`wan2.5` / `wan2.6` 系列官方上限 1500 字，系统自动截断；`wan3.0` 系列保持 2 万字。避免切换到旧版模型后因提示词过长被判供应商失败。

各版本参数差异（选型时注意）：

| 模型 | 提示词上限 | 时长 | 声音 |
| --- | --- | --- | --- |
| `wan3.0-video` / `wan3.0-video-prime` | 较高（系统按 2 万字截断） | 2–30 秒 | 可开关 |
| `wan2.6-t2v` | 1500 字 | 2–15 秒 | 固定有声 |
| `wan2.5-t2v-preview` | 1500 字 | 2–15 秒 | 固定有声 |

界面的时长下拉仍按 2–30 秒展示；给 `wan2.5` / `wan2.6` 选择超过 15 秒时，由供应商返回错误（记为 `video_provider_failed`）。

受控测试新增「业务空间旧版万相按模型限制提示词长度」：`wan2.6-t2v` 3000 字提示词被截断为 1500，`wan3.0-video` 保持 3000 字不变。

## 2026-11-17：多账号共用同一条视频

任务新增选项「多个账号共用同一条视频」（`spec.shareVideo`），位于「任务 → 生成与发布 → 视频比例」下方。默认关闭，行为保持原有的一账号一条成片。

**执行语义**　开启后，同一次运行内全部视频目标共用一条成片与一份文案：编号最小的视频目标负责写文案并调用视频模型生成；其余视频目标先进入 `waiting_share`，待成片完成后复制同一成品（标题、正文、视频、封面）并各自分发到自己的账号。文章与图文目标不受影响，仍按账号独立生成。

**失败与接管**　低编号视频目标被阻断或取消后，等待中的目标不再等待，由当前编号最小的可用目标接管生成，因此单个账号的页面或账号问题不会拖死整条运行。停止运行会同时取消 `waiting_share` 目标。

**计数**　共用模式下一次运行只消耗一次文案调用和一次视频生成；视频生成次数上限按运行计算，不受共用影响。费用预留同样只发生一次。

**重启**　`waiting_share` 目标按运行快照重新扫描，发现已有成片即接管并转为待分发；生成器与等待者都不需要人工重跑。

**素材引用**　接管后的目标写入相同的 `artifact` 与 `asset_usage`；素材删除保护补充了 `generatedVideoId`，成片在未分发前不会被误删。

**界面**　任务详情新增状态「等待共用视频生成」。勾选后建议保持默认的「每次运行最多 LLM 调用次数」，实际消耗低于上限不会额外计费。

**受控测试**　`test/video-share.test.mjs` 覆盖三种情形：共用时两个账号只产生一次文案与一条成片且分发同一 `generatedVideoId`；不勾选时两个账号各自生成；混合目标（文章 + 两个视频）中文章独立生成、两个视频共用。三项均通过。
