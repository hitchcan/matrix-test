# 视频模型配置与自动发布

2026-11-12。本轮完成用户在任务中选择视频模型、调用 API 生成视频并继续发布的配置与执行链路。保留从素材库直接上传原视频，以及 agent 按日期区间选原视频的功能。

## 使用方法

1. 在“任务 → 模型配置”保存可用的 agent 文本模型。agent 负责标题、配文、镜头计划及完整视频提示词，视频服务负责生成成片。
2. 在独立的“视频模型配置”中选择“阿里云百炼 · 万相3.0”，填写所属地域、业务空间 Workspace ID，点击“填写万相接口地址”；也可以粘贴控制台提供的完整生成接口。
3. 填写视频模型名称（默认 wan3.0-video）、对应地域的 API Key，选择时长、分辨率、是否生成声音和每次运行的生成次数限制，保存配置。可选费用估算和上限可同时留空，此时以次数限制执行，实际收费以供应商为准。
4. “保存并检查配置”只做本地检查，不发送生成请求，不代表密钥权限或成片质量已经验证。
5. 新建任务选择“AI 生成”，填写主题、事实、账号定位，选择目标账号的“AI 视频”，在“生成与发布”选择视频模型、横竖比例和定时。要全自动提交请选择“自动发布”；选择“发布前人工处理”时仍会在最终提交前等待用户。
6. 保存并立即运行，或等待定时触发。运行详情可以查看视频模型任务状态、原始任务 ID、视频提示词和生成视频预览。视频和封面自动保存到素材库。

现有视频无需调用生成模型：选择“手选素材直接发布”，勾选视频并设置标题和配文；或者选择“agent 从日期区间选材发布”，让 agent 依据素材备注挑选原视频并编写配文。

## 模型切换

视频配置与文本模型配置互相独立。可保存多份视频配置，设定默认值，并让各个任务选择不同配置。任务选择“使用默认”时，会在创建新运行时确定配置 ID；之后切换默认不会改变该运行。

当前支持两类协议：

- 万相原生异步协议：可配置模型名称、完整地域接口、时长、分辨率、声音开关和密钥。
- JSON 异步网关：用于后续接入不同供应商。将其原生协议适配到下面统一的创建/查询/下载合同；仅修改地址不会自动兼容任意厂商的请求字段。

万相接入按[阿里云官方 API 参考](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)核对：创建接口使用 Workspace 与地域域名、Bearer 鉴权及 X-DashScope-Async: enable；提交 prompt 和视频参数，保存返回的 task_id，再查询同一空间的 tasks 接口，成功后下载 video_url。官方支持的地域、模型权限与密钥需要一致，本实现提供2–30秒和480P/720P/1080P选项。

本轮使用文生视频，不会把素材库的原图片、视频直接上传至万相作为首帧或参考媒体。素材可以用于 agent 理解和编写提示词。万相参考生视频等其他模式不在本轮接入范围。

## 执行与恢复

创建远程视频请求前，事务保存一次生成名额；已发出但响应不明的请求不会自动重建。每个目标只创建一段完整视频，不对每个镜头分别调用视频服务。费用估算为空时只记录次数，不虚构实际金额。

远程 ID 和原视频配置 ID 持久保存，重启后继续查询原任务。临时网络或查询限流失败会在原任务上有限等待重试；持续失败会阻断，可修复后恢复同一目标。凭证错误也会阻断，不将供应商原始报错正文写入运行详情。

切换默认配置或为新任务选择另一配置不影响已在生成的视频。若直接编辑旧配置的接口、模型或视频参数，旧远程任务会因签名变化暂停；恢复原参数后可恢复同一目标。仅更新同一接口的密钥不改变签名。旧环境变量视频任务继续使用环境配置，不会被新默认配置接管。

下载先校验结果主机，不向下载地址携带视频 API Key，并限制文件大小。成片经本地浏览器解码，提取封面、时长与尺寸后归档。之后仍通过原有分发、身份核对、AI 声明和提交门禁。停止运行会阻止迟到结果继续分发；已提交到供应商的生成请求不会因此自动取消，也不能保证供应商不计费。

## JSON 网关合同

将 endpoint 设置为创建接口，例如 https://gateway.example/video/jobs。

创建：POST endpoint，携带配置的 Bearer 密钥，提交：

```json
{
  "model": "future-video-model",
  "request_id": "稳定的本地目标ID",
  "prompt": "agent编写的完整视频提示词",
  "aspect_ratio": "9:16",
  "duration": 5,
  "resolution": "720P",
  "audio": true
}
```

返回 `{"id":"remote-id"}`。网关可用 request_id 实现自己的幂等防重，本地即使网关没有幂等能力也不会自动重发结果不明的创建请求。

查询：GET endpoint/{编码后的remote-id}，仍携带 API Key。返回 `{"status":"running"}`、`{"status":"failed"}` 或 `{"status":"succeeded","video_url":"https://result.example/output.mp4"}`。

结果视频需为本地浏览器可解码的 MP4。下载主机默认为配置接口的主机；若使用独立结果域名，填入“允许下载的额外域名”。万相官方结果域名已内置。重定向不自动跟随，下载不携带接口密钥。

## 数据与接口

- GET/POST /api/video-settings：读取脱敏配置或保存配置。保存支持 id/create/activate/name/provider/endpoint/model/key/clearKey/duration/resolution/audio/downloadHosts/callMicros/maxMicros/maxGenerations。
- POST /api/video-settings/select：传 id 设置默认配置。
- POST /api/video-settings/check：传 id 执行本地参数检查，不发出模型请求。
- TaskSpec 新增 videoModelId；agent 的 save_template 工具使用同一字段，context 返回脱敏 videoProfiles。
- studio.sqlite 新增 video_profiles、video_settings；视频任务迁移16新增 profile_id、poll_failures。历史远程 ID、预算与状态保留。

凭证仅存本机，HTTP 状态、agent context、运行快照及成品不返回密钥。切换供应商或生成接口时不会沿用旧接口密钥。环境变量 MATRIX_VIDEO_* 接入继续兼容；旧环境变量方式仍沿用原有费用配置约束。
