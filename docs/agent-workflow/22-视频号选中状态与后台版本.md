## 修改

1. 选中状态按单次DOM快照读取：has-value、select-display内的select-value、橙色is-selected选项及is-open。使用textContent读取专用值节点，不依赖整个下拉框的innerText或隐藏菜单文字。显示值与选中标记矛盾时等待短暂同步，仍矛盾则暂停并输出状态诊断。
2. 已选目标且关闭时完全不点击；已选目标但打开时仅关闭一次选择框，不点击选项。未选目标时打开菜单后先重新读一次状态，防止菜单加载期间恢复默认选中值后再点同一项取消。
3. 只有不带is-selected的唯一目标选项可以被选择。选择后等待官方自动关闭，不再通过开关额外收尾。选中目标、自动关闭后可继续。
4. 提交前复核明确为只读，不再打开或改变声明；异常保留选中值、菜单开关、一致性和选中数量等脱敏诊断。声明状态错误不进入模型恢复并重放整段上传流程。
5. 后台在/api/state暴露已加载的声明适配修订值；网页与后台不匹配时显示“后台仍运行旧版，请先停止原服务再启动”。启动端口已占用时明确说明新代码未启动，而非让用户误以为新服务已替换旧服务。
