# 任务与模型配置

2026-11-12。按用户本轮要求，界面统一使用“任务”，原有模板、运行快照、agent 工具及 HTTP 路径继续兼容。01–03 是此前的调研和规划记录，其中旧称及本地模板视频设想以用户后续要求为准。

## 使用流程

1. 打开“任务”，填写模型配置中的完整 Chat Completions 接口地址、模型名称和 API Key。使用视觉模型时勾选“模型支持图片输入”。可命名保存多份配置，在下拉框中编辑或选择，点击“设为 agent 模型”切换默认模型。普通保存不调用模型；“保存并测试连接”会发送一次短请求，显示连接结果和耗时。
2. 填写主题和写作要求。按平台筛选账号，在账号卡片内选择长文章、图片笔记或 AI 视频；一个账号可选多种形态，筛选不清空选择。
3. 从素材卡片选择图片或视频，可搜索名称、筛选类型、按归档开始及结束日期过滤并补充描述。日期区间包含边界，筛选不清空选择。也可在“事实与参考资料”下面选择上传归档日期，批量上传参考图片或视频；文件自动保存到素材库并选中，已有文字和账号选择保留。沿用素材库的单文件 512 MB 上限，图片与视频均可上传。
4. 选择素材使用方式：名称与描述模式适用于普通文本模型；读取内容模式将图片和视频采样画面交给视觉模型。也可勾选本地图片 OCR。
5. 设置时间、发布方式与预算，保存任务，再手动运行或等待计划时间。每个账号单独生成；运行详情可查看成品及分发进度。

仅使用素材写作时，事实资料可留空；没有素材时仍须填写事实资料。文章会把模型选中的图片嵌入正文；视频素材作为文章的画面参考，不能作为文章图片附件。图片笔记仍须有图片。

## 可选的独立写作对话

默认由 agent 模型直接生成。勾选“使用独立写作对话，由 agent 编写提示词”后，选择任意已保存配置（可与 agent 使用同一份配置、同一供应商及同一模型）：agent 根据主题、定位、事实与授权素材编写提示词，指定的写作模型再生成结构化稿件。文章、图文及视频场景描述都经过相同的事实、素材 ID 和输出校验；视频成片依旧交给视频服务。

视觉模式下 agent 需要视觉能力。视觉写作模型可继续接收所选采样画面；普通文本写作模型接收 agent 生成的画面说明及同一授权素材元数据。不会给普通文本模型发送无法处理的图片输入。规划与写作所用配置及凭证在开始生成时捕获，生成中切换配置不改变该次调用的目标。

规划和写作是两次独立 Chat Completions 请求，各自有系统指令与用户输入，不复用浏览器恢复对话历史。每个目标预留两次 LLM 调用及两份单次预留费用，预算不足时不发出请求；仍沿用 MATRIX_WRITER_CALL_MICROS 的统一保守估算，供应商实际账单以其记录为准。失败或中断时已预留名额保留，结果未知不会自动重调；停止运行后迟到的提示词不会启动写作模型。成功成品保留 agent 提示词和两份配置 ID，可在运行详情中展开查看。

## 数据与接口

GET /api/model-settings 返回当前 agent 的 endpoint、model、vision、hasKey、configured、source，以及 activeId、脱敏 profiles，不返回密钥。POST /api/model-settings 接受 id、name、create、activate、endpoint、model、key、vision、clearKey；create=true 新建，id 更新指定配置，activate=false 只保存，修改当前活动配置仍立即更新。原单配置调用方式保持兼容。POST /api/model-settings/select 接受 id 切换 agent；POST /api/model-settings/test 接受 id 测试已保存配置。所有写接口沿用本机、同源和令牌限制。

用户配置保存在本机 studio.sqlite 的 model_profiles 表，model_settings 保留活动配置；已有单配置启动时自动迁移。没有保存用户配置时，沿用 MATRIX_MODEL_ENDPOINT、MATRIX_MODEL_NAME、MATRIX_MODEL_KEY，可用 MATRIX_MODEL_VISION=1 声明视觉能力，环境变量配置也可以从列表选择。密钥输入留空时，仅在同一配置且接口地址相同的情况下保留；新建配置不继承别的配置的密钥。更换接口地址需重新填写密钥。可勾选清除密钥。

保存后后续模型调用即时生效，正在进行的请求继续使用开始时的配置。运行和分发记录不包含密钥，也不保存发送的图片 data URL。TaskSpec 使用 sourceMode：description 或 content；generationModelId 为空表示直接生成，配置 ID 表示两模型写作。历史模板默认直接生成。

连接测试最长 20 秒，只检查接口连通、鉴权、模型调用及 JSON 结构化响应；不发送任务资料、不发布内容，不代表视觉能力、写作质量或视频接口已经验收。测试失败只返回通用诊断，不回传供应商原始错误正文或凭证。

## 素材理解边界

读取内容模式一次最多 8 份素材，每份不超过 150 MB。隔离的本地浏览器解码所选文件，将最长边缩至 768 像素后转 JPEG；视频提取开头、50%、90% 三处画面，并标注时间点。仅这些画面发送给用户配置的 LLM，不发送原视频，不读取音频，不假定采样画面覆盖完整视频情节。该模式要求模型支持图片输入；缺失能力时明确阻断，补齐配置后可恢复原目标。

LLM 根据参考画面生成文章或视频场景描述。AI 视频仍由独立视频模型 API 生成，当前没有把原素材直接传入万相进行图生视频或视频编辑。万相的费用、真实调用与成片质量验收继续按 TD-VIDEO-WAN3-001 延后。

## 删除已保存任务

已保存任务行提供“删除”，确认后移除任务模板并停止后续定时创建。已有运行、成品和分发记录保留，正在执行的任务需在运行详情中单独停止。历史运行继续显示创建时的主题。删除使用版本校验，页面版本过期时需刷新后重试。HTTP 支持 POST /api/task-templates/{id}/delete，参数 expectedVersion；也可 DELETE /api/task-templates/{id}?expectedVersion=N。agent 工具 delete_template 接受 id、expectedVersion，共用同一删除服务。

## 2026-11-13：任务页面折叠显示

模型与视频模型已有可用配置时默认收起，只显示与检索配置一致的标题栏及状态；没有可用配置时默认展开引导填写。点击标题栏或用键盘Enter/空格可展开/收起。内容要求、目标账号、素材与配图、生成与发布、恢复设置、已保存任务及最近运行同样支持独立折叠。

折叠只改变显示，不移除表单控件，不清空未保存文字、账号选择或素材。当前浏览器标签页记住用户手动展开/收起的偏好；自动刷新和重新渲染时恢复偏好。提交或配置校验发现折叠区中的必填字段无效时会自动展开对应区域，便于定位填写。此项为前端修改，刷新页面即可加载，不需重启发布后台。
