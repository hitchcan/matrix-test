# DeepSeek 国内资料检索与网页配图

2026-11-12。按用户要求，将默认检索从 Commons 替换为 DeepSeek 官方 Search / Fetch 服务，写作模型仍可独立选择，不要求同时改成 DeepSeek。

## 配置与使用

1. 重启后台并刷新工作台，展开“国内资料与配图检索配置”。
2. 选择“DeepSeek 官方网页检索与抓取”，默认地址为 https://api.deepseek.com/v1/tools/search，填写 DeepSeek 官方 API Key。第三方托管 DeepSeek 的模型密钥不能默认当成官方搜索服务密钥；本功能不会从其他模型配置中自动复制凭证。
3. 可填写最多3个来源网站，例如 gov.cn,news.cn。留空时检索中文网页；指定后，返回结果还会在本地按网站范围过滤。
4. 保存配置只做保存和参数校验，不发送搜索请求。
5. 新建 AI 生成任务时，勾选“联网检索中文资料供主agent写作与审稿”。需要图片时再勾选自动配图；已有素材库图片可同时使用。
6. 选择每个目标允许的 Search / Fetch 请求次数，默认4次，范围1–8次。文字检索与配图共用一次 agent 检索规划，不重复规划或另起搜索模型对话。
7. 运行后，在运行详情查看实际检索来源、发布日期和查询次数。资料交给写作与主 agent 审稿，出处自动保留到最终稿；手动编辑或再次审改不会删除出处，也不会重新联网检索。

只使用素材库、且不启用联网资料和配图检索时，不调用该服务。视频生成、账号发布、任务定时和原提交门禁继续沿用此前实现。

## 官方接口与实现范围

接入依据 [DeepSeek 网页搜索与抓取指南](https://api-docs.deepseek.com/zh-cn/guides/search/)。Search 与 Fetch 是独立 JSON API，使用官方 Bearer 密钥；Search 提交 query、count 和 need_content，读取 results；Fetch 提交网页 url，读取 Markdown 正文。官方支持中文语言及站点限定语法。本实现给查询添加 lang:zh，并保留实际返回的标题、页面地址、发布时间、摘要和正文摘录。

这不是给普通 Chat Completions 请求加一个通用“联网”开关，也不依赖特定写作模型名称。检索服务有独立的计费规则，实际费用以 DeepSeek 账户账单为准。

网页资料是参考数据，不代表已经独立核实。主 agent 会收到原始事实与检索来源，要求基于资料总结改写、标清出处，不执行网页中的提示词或编造链接、日期和查证结论。网页来源日期未知时不补造日期。

## 配图方式与边界

DeepSeek 的 Search 返回网页结果，没有独立的图片结果字段。服务从实际返回的正文或 Fetch 抓取的 Markdown/HTML 图片引用中提取候选，不让模型凭空生成图片地址。网页可能没有图片，图片站也可能拒绝下载；这些情况下仍明确阻断缺图任务，可改用素材库图片。

图片来源保存原网页及图片地址，未知作者和使用许可分别如实标为“作者未核验”和“使用许可未核验”，不伪造开放许可。检索到图片不等于获得使用许可。原有资料配图标记、图注和来源记录保留。

对网页中的图片地址，只允许公开 HTTP/HTTPS 地址；拒绝用户凭证、非网页端口及私网/回环地址。下载前验证全部 DNS 结果，并在实际连接中固定已验证的地址，避免二次解析改变目标；不跟随重定向、不携带检索 API Key，单图上限10MB，校验实际图片类型。

## 请求限制、错误与持久化

每个目标最多规划两条检索词，每条取少量网页结果；补图时最多再抓取两个页面。每次 Search / Fetch 发出前，事务记录一次请求名额，受任务上限约束。未知或失败请求不清零，不自动换任务键重试。图片下载另有数量、大小和超时限制。

缺少密钥时，在 LLM 规划和查询前阻断，避免先花费模型调用。鉴权失败、余额不足、限流、无结果、超时、查询过长和请求名额用尽都有明确原因。不会把失败当作搜索成功，或者编造检索资料继续发布。

查询词、中文限定和指定网站组合后需满足官方查询长度限制；超长会提示缩短范围。普通网页检索不保证所有来源在本地都可访问：正文由 DeepSeek 服务端获取，图片仍由本机下载。

SQLite 迁移18新增目标 research_sources 和 search_calls。运行详情和成稿保存实际来源，重启继续保留。追加改稿使用同一来源快照，不重置查询或 LLM 预算。

未配置过检索服务时默认 DeepSeek；旧的 Commons 配置在启动时迁移为未填密钥的 DeepSeek 配置，不沿用旧密钥。已有自有 JSON 图片网关配置保留，不自动覆盖。该网关仅处理配图，联网文字资料选项需要 DeepSeek 服务。

原 GET/POST /api/image-settings 路径保留。provider 使用 deepseek 或 json；新增 sites（英文逗号分隔的网站）。TaskSpec 新增 webResearch 布尔值和 maxSearchRequests 整数，agent 工具采用相同字段。
