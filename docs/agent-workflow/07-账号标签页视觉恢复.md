# 账号标签页内的分级视觉恢复

日期：2026-11-12。视觉恢复直接复用当前账号的 Playwright context 和任务标签页，不依赖 Windows 桌面控制、额外浏览器进程或 computer-use 插件。

2026-11-13更新：准备阶段现已支持由任务缺口派生的目标约束坐标操作，见 [任务目标约束的坐标恢复](./15-任务目标约束的坐标恢复.md)。下文固定按钮限制仍适用于没有明确目标的旧安全模式及核对页；目标坐标模式以15为准。

## 开启方式

1. 在“任务 → 模型配置”选择支持图片输入的 agent 模型，并勾选其图片输入能力。连接测试检查 JSON 调用，视觉理解能力仍需对应服务实际支持。
2. 在任务的“恢复、预算与发布后核对”中勾选“结构化恢复失败后启用账号标签页视觉操作”，设置升级前结构化调用次数，默认 2 次。“内容工作室 → 发布选项”也提供相同设置。
3. 保存后创建运行。该权限和阈值随发布任务策略保存；历史任务没有该权限时不自动开启截图与视觉操作。
4. 分发详情显示恢复层级、视觉调用数和总调用预算，可以停止任务或接管原账号页。

TaskSpec / dispatch 的 publicationPolicy.recovery 新增 visualEnabled（默认 false）及 structuredCallsBeforeVisual（1–32，默认 2）。agent 的 save_template 工具 Schema 同步支持这些字段。

## 升级与预算

先运行现有脚本；准备失败后进入结构化 agent 恢复。达到阈值或结构化准备轮数上限后，进入视觉阶段。默认全局恢复上限为 4 次模型请求，正常分配为前 2 次结构化、后 2 次视觉。总预算较小时提前升级，尽量给视觉动作和复核保留两次请求。

两个阶段共用原有次数、截止时间及费用预留账本。MATRIX_RECOVERY_MAX_CALLS 控制全局请求上限，MATRIX_RECOVERY_MAX_SECONDS 控制时间，原恢复费用配置继续有效；单次预留费应覆盖视觉请求的估算费用。截图观察不会产生额外隐含模型调用。每次回复最多一个动作，点击、滚动或恢复标题后必须重新观察，不能一次返回操作脚本。

迁移 15 在 recovery_incidents 增加 visual_calls 和 recovery_level。切换阶段及重启不清除已用次数。达到预算、缺少视觉模型或目标页面能力时转人工，不通过换任务绕过原提交次数。

## 视觉观察与动作

模型接收当前任务页的脱敏布局截图及安全控件列表。页面文字、输入框、编辑器内容、图片、视频、Canvas、SVG、iframe、页眉及侧栏等会被隐藏或遮盖；仅发送经过白名单筛选的按钮标签和几何信息。截图保存在内存中，使用 image_url 图片输入传给所配置模型，不写入 SQLite、任务日志或截图文件。

当前开放：选择列表中的安全按钮进行原生鼠标点击、当前文档上下滚动、把空标题恢复为可信任务快照，以及请求标准复核或本人处理。图片故障还可以请求标准图片上传重试。安全按钮包括关闭、取消、知道了、稍后再说、返回编辑、继续编辑、收起、重试、重新加载等。模型不能提供任意文字、坐标、选择器、网址、Shell、脚本、键盘快捷键或文件路径。

这是受控的视觉恢复能力，不是任意操作网页的通用代理。白名单外控件、复杂表单、任意文案修改、未知上传入口、支付及账号安全操作不开放。无法确认的动作保持阻断，不能保证所有平台异常都能自动完成。

## 标签页与发布门禁

- 动作绑定官方 origin、账号 session、页面对象、document、一次性 token 和保留的控件句柄。截图前后控件布局需一致；等待模型时 DOM 改变、任务停止、用户接管或页面更换后旧动作无效。
- 点击前重新检查身份、控件语义、可见性、遮挡及任务所有权。发布、提交、删除、声明、授权、登录等控件不进入操作列表；模型不能通过输入 Enter 或执行脚本提交。
- 视觉阶段拦截当前页 POST 等写请求、主文档导航以及该页发起的新窗口；不会控制其他账号页。上传、自动保存和最终发布必须回到标准工作流。若页面被 Service Worker 控制而无法可靠拦截网络，则停止视觉恢复并转人工。阻断导航有可能使该标签页显示浏览器错误页，此时继续保持人工处理，不跳转到其他页面执行。
- 普通准备恢复后，在仍属于该平台编辑器的原页重新填写并标准核验，避免刷新丢失已修复的界面状态。最终发布仍只在原持久提交门禁中执行。
- 创作中心核对使用其原独立只读标签页进行视觉恢复，不能切换到提交页；恢复后仍由标准 verifier 读取完整状态，模型不能自行宣告发布成功或稿件缺席。

## 验证范围

受控 Chromium 检查涵盖安全提示关闭、遮挡和 DOM 变化失效、一次性 token、跨账号页及 session 更换隔离、导航和弹窗阻断、当前页写请求拦截、可信标题恢复、原页标准复核、分级升级、共享费用/次数、停止后的迟到响应和缺少视觉能力的阻断。网关测试确认截图使用图片输入，正文不包含截图 Base64。未调用真实付费视觉模型或执行真实平台发布。
