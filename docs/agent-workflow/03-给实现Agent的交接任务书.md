# 给实现 Agent 的交接任务书

日期：2026-11-11。项目：`E:\矩阵调研2\matrix-studio`。

## 1. 可直接复制的任务指令

> 请在现有 Matrix Studio 上实现持久化智能体内容工作流。先阅读本地适用的 AGENTS.md，然后依次阅读 docs/agent-workflow/01-技术调研报告.md、02-实现规划与验收规范.md 和本任务书。三份文件是本次实现的交付规范；不要仅根据项目旧 README 判断“提交未知永远不允许自动重发”。
>
> 最终目标：用户只设置宏观任务（主题/定位、定时、内容形态、平台账号、素材范围、预算、核对和重发参数），系统自动选材，调用模型生成图文/长文/模板视频，完成多账号发布；普通脚本异常先由规划 agent 在原账号浏览器中诊断恢复；短信/扫码/本人验证等再交给用户。提交后主动进入创作中心查稿，根据实际稿件状态继续监控；多次有效检查超时仍无作品时，按用户配置冷却并有限重发。
>
> 按 W0–W9 工作包推进。先完成 W0–W5 的“已有稿件 + agent 恢复 + 查稿 + 有限重发”闭环，然后继续宏观任务、素材理解、图文长文生产、其余平台核对和模板视频。阶段性可验收，不得将首个单平台演示宣称为全范围完成。
>
> 沿用 Node.js ESM、SQLite、Playwright 和现有工作台，不先做无关框架重写。将业务从 server.mjs 逐步抽为服务，HTTP、agent 工具和 worker 共用同一校验/提交逻辑。保留 createStudio 的可注入运行时，并增加可注入 clock/model/verifier。
>
> 用户已明确希望普通异常由 agent 优先处理，并允许按保存的策略有限重发；这些动作不需要逐次再问确认。历史任务未配置此权限则不自动重发。真实平台规则要求的本人确认或身份验证仍需保留。文档里的平台/模型候选不是现有密钥或权限，不能假定已经可用。
>
> 必须使用真实可配置的模型网关与结构化浏览器动作循环，不能以 if/else 脚本或 fake 模型冒充 agent。fake 用于测试；缺少模型凭证时继续完成独立开发与受控测试，清楚标注实际模型和账号联调未完成，不伪造调用记录。
>
> 全部最终发布入口经过持久提交门禁，最多首次加 maxResends 次，提交不明仍占名额。重发先核对账号和创作中心，检查审核中/定时/草稿/拒绝等状态、页面完整性、时间窗和分页；有效缺席、冷却、次数、截止时间与最后查重都满足后才创建新 attempt。不得清掉 submitting 历史、新建 requestKey 或换 revision 绕次数。不要直接放开原 retry 接口的防重限制。
>
> 接管现有账号 context，不另开浏览器进程争用 Profile；保留原提交页，另用同 context 的 verifier 页查稿。脚本、agent、核对和人工控制权互斥，过期页面 token 不执行；模型等待/冷却期间不长期占全局物理操作锁。普通浏览器工具不能绕 gate 点击最终发布、提交表单或按 Enter 完成发布。
>
> 保留账号隔离、身份与文案复核、AI 声明、素材引用保护、同源及令牌校验、演示模式和历史快照。AI 使用声明依据实际创作方式，不让模型为了通过校验随意取消。保持日志、截图和模型上下文脱敏，不读取真实 Cookie、验证码或凭证来作为调试素材。
>
> 修改后完成适当的单元、受控 Chromium 和集成测试，覆盖规范中的 A01–A34；执行 npm run check 与 npm test，并明确哪些平台通过真实账号验收。真实发布不作为默认回归测试；用受控页面测试重发上限和迟到重复。若需要真实模型/账号输入，说明最小缺失配置，并继续不依赖这些输入的工作。
>
> 每阶段交付代码/迁移/必要配置/测试证据/能力矩阵和剩余工作，不把受控页面的成功写成真实发布成功。最终交付启动运行指南、任务设置示例、异常接管与停止方法、重启恢复说明、模型费用和证据保留配置。

## 4. 不得缩减的验收底线

1. 普通异常优先 agent；需要本人处理时保留会话，恢复后不盲目重发。
2. 原页提交提示与创作中心查稿两层核对，不把一条 toast 当最终公开成功。
3. “没看到”有覆盖证据；页面报错、只看第一页、候选歧义不触发缺席重发。
4. maxResends 可设 0/1/2/更多合法值，冷却与计数持久化；实际最终动作从统一 gate 发出。
5. 已审核中/定时等待不因尚未公开而新建同稿；旧稿迟到停止后续重发。
6. 重启后没有原 Page 也能独立查稿，不能依赖内存 pendingSubmissions 才能继续。
7. 同一宏观任务能分出长文、图文、视频，且各账号媒体/文案隔离；成功目标不随其他目标失败重发。
8. 文档、UI 和能力矩阵对已实现/未实现/受控测试/真实验收表述一致。
